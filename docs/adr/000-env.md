## SpeechTranscriber `ar_SA`

Not checked. `SpeechTranscriber` is a macOS 26 SDK API; the only SDK here is 13.3 and Swift 5.8.1,
so a test script cannot compile. Re-run after Xcode is installed.

## Decision

- No Xcode → per the brief, stop after Step 1. Steps 2–4 (package build/test, T04 capture,
  T04b panel-test) not started.
- Even without the brief's rule, the CLT toolchain cannot build T04: Core Audio process taps need the
  macOS 14.4 SDK, and Swift 5.8 is older than what CI uses.
- Swap was 6.6 GB (above the brief's 6 GB stop line), so no build was attempted.

## Owner actions

1. Install Xcode from the App Store (Apple ID is owner-only), open it once, accept the licence.
2. `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` (needs the owner's password).
3. Optional for later signing: sign in to an Apple ID in Xcode → Settings → Accounts (0 codesigning identities now).
4. Free RAM before builds (swap near full with 5+ Claude sessions open).
